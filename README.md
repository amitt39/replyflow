# ReplyFlow

ReplyFlow is a customer support inbox application built with React. It helps support agents manage customer tickets and conversations in one place.

## Features

- **Dashboard:** View ticket statistics, ticket volume, and recent tickets.
- **Inbox:** Search, filter, and sort support tickets.
- **Ticket Details:** View customer conversations, send replies, and add internal notes.
- **Ticket Management:** Update ticket status and priority.
- **Customers:** View customer information and their ticket history.
- **Profile Settings:** Update and save agent profile information.
- **Inbox Preferences:** Choose the default ticket sorting order.
- **Theme:** Switch between light and dark modes.

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- React Router
- Vite
- localStorage

## Note

The UI styling was created with AI assistance. All React logic and functionality were written manually.

## Run Locally

```bash
git clone https://github.com/amitt39/replyflow.git
cd replyflow
npm install
npm run dev
```
